# JARVIS AI HUB - Notas de Lançamento (Release Notes) v1.0.0

**Versão:** `v1.0.0-stable`  
**Data:** 06 de Novembro de 2026  
**Status:** Produção Local-First Concluída  

---

## 1. Destaques da Versão 1.0.0

- **Soberania e Privacidade Local-First**: Funciona de forma 100% autônoma e offline. Todos os modelos rodam localmente via Ollama (`llama3.2:3b`, `qwen2.5:7b`, `qwen2.5-coder:7b`).
- **Núcleo de Segurança Inviolável (`SecurityCore`)**: Modelos de IA não têm permissão para autoaprovação de operações. Todas as gravações em disco, comandos de shell e execuções críticas passam por portões de autorização humana com diffs unificados e botões de decisão.
- **Roster Completo de 26 Agentes Especializados**: Do Product Manager ao Rust/C# Developer, DBA, QA Engineer e Pentester, todos integrados via LangGraph e router interagente com proteção anti-loop (máximo 3 ciclos).
- **Interface Web e Móvel Unificadas**:
  - **Dashboard Web**: React 19 + TypeScript + Vite servido nativamente pelo backend FastAPI.
  - **App Móvel**: Flutter para Android com suporte a túnel ponto-a-ponto via VPN Tailscale sem exposição de portas na internet.
- **Proteção Git e Reversibilidade Total**:
  - Branches isoladas `jarvis/task-xxx`.
  - Salvaguarda automática de alterações pré-existentes do utilizador.
  - Mecanismo de rollback testado e comprovado.
- **Capacidades Analíticas e de Voz**:
  - Pipeline de dados para CSV/JSON/SQLite com validação e redação de credenciais.
  - Runtime de voz local (STT e TTS) push-to-talk.
  - Motor de manutenção proativa com respeito estrito a tetos orçamentais.

## 2. Instruções Rápidas de Inicialização

### Iniciar o Backend e Dashboard
```powershell
.venv\Scripts\activate
uvicorn apps.api.main:app --host 0.0.0.0 --port 8000
```
Acesse: `http://localhost:8000/`

### Executar a Suite Completa de Testes
```powershell
.venv\Scripts\pytest
```
Resultado: **61 testes de integração e unitários passando em ~2s**.

### Iniciar a App Móvel Flutter
```powershell
cd apps\mobile
flutter run
```
